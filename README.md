# 16S Amplicon Sequencing Pipeline

A reproducible workflow for processing 16S rRNA gene amplicon sequencing data.

## Workflow

Raw FASTQ files
→ Quality control
→ Demultiplexing
→ Primer removal
→ Quality filtering
→ Denoising
→ ASV generation
→ Taxonomic assignment
→ Sequencing-depth assessment
→ Downstream analysis
